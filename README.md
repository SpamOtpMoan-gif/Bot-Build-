# ☠️ XOW TELEGRAM BOT BUILDER WORKER ☠️

## Deskripsi
Worker GitHub + Cloudflare untuk build APK Telegram Bot otomatis.

## Cara Pakai:
1. Clone repo ini ke `Bot-Build-`
2. Set GitHub Token di Secrets (GITHUB_TOKEN)
3. Deploy `worker.js` ke Cloudflare Workers
4. POST ke `/build` → trigger build APK
5. GET ke `/status` → cek status build
6. Download APK dari GitHub Actions artifact

## Endpoint Worker:
- `POST /build` → trigger build
- `GET /status` → lihat status
